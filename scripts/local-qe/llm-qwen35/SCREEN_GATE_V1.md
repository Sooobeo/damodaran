# 의미 전용 개발8 조기 중단 규칙

기존 개발48의 중요 오류14개와 원래 판정을 보존하고 새 구성의 첫 진단만 제한한다. [선택 기록](../../../.training/quality-evaluation/qwen-semantic-v2-dev8/selection-v1.json)은 기존 미탐3개, 별도 시간 범위 오류1개, 정상4개를 새 모델 출력 전에 고정했다. 원문 SHA → 번역 SHA → ID 순으로 명시된 후보군의 동률을 결정했다. 009·010은 해시는 다르지만 최소대립 문장으로 독립 표본이 아니다. 정상4개가 우연히 모두 Hy7로 선택됐으며, 전체 모델·집합·교차집합 평가를 대신하지 않는다.

[`screen_gate_v1.py`](screen_gate_v1.py)는 모델 밖의 개발 평가기다. `identity()`가 동결 입력·선택·GT의 SHA와 고정 순서를 검증하고, `check(row_id, mapping)`은 새 v3 매핑의 실제 bool 경고와 원래 정답을 대조한다. 정답·이전 판정·선택 이유·ID를 모델 요청에 넣지 않는다. 이 파일에 정답이 존재한다는 사실과 모델에게 정답을 제공했다는 주장을 혼동하지 않는다. 실행기는 source/translation/context만 전달한 요청과 원시 응답을 보존해 이 경계를 검증해야 한다.

원시 응답·종료토큰·잘림·실제 template/token·sampling·엄격 계약·guard를 먼저 확인하고 assessment를 저장한 다음, 첫 FP/FN이면 다음 generation을 시작하지 않는다. 이유 문구에서 특정 단어를 찾아 경고로 올리지 않는다. 무효/미완료 결과는 정상으로 비교하지 않고 기술 실패로 중단한다. 실행기에서 고정 순서·이미 수행한 행·마무리 무결성·소유 프로세스 종료를 별도로 집행해야 한다.

관측한 이 오류를 그대로 포함하는 전체48이라면 FN 하나의 재현율 상한은13/14=92.86%, FP 하나의 정밀도 상한은14/15=93.33%다. 이 수치는 **현재 출력을 유지한다는 조건부 상한**이며, 다시 추론했을 때 나올 출력의 수학적 예측은 아니다. 재추론에서 좋은 결과를 골라 채택하는 반복을 하지 않기로 사전에 정한 개발 중단 규칙이다. 8개 모두 맞아도 전체95/95·필수6개·의미 구간 정밀도 통과나 앱 등록은 아니다. 8개를 전체48 결과에 자동 합치지 않는다.

합성 검사는 동결 자료 정체성, 고정8개 정답과 반대 경고, 첫 오류 상한, null/숫자 bool/이전 버전 거부, 정답 파일 변경 거부, reason 문구를 통한 승격 거부를 확인한다. 모델 호출과 의미 품질 검증은 없다.

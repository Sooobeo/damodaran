# 초기 학습 콘텐츠

[index.ts](index.ts)는 네트워크 없이 읽을 수 있는 정적 편집 콘텐츠다. `resources`, `modules`, `glossary`, `toolGuides`와 각각의 TypeScript 인터페이스를 내보낸다.

| 콘텐츠 | 개수 | 고정 ID |
|---|---:|---|
| 자료 | 36 | R01~R20, B01~B06, T01~T10 |
| 단원 | 8 | M01~M08 |
| 용어 | 44 | G01~G44 |
| Excel 가이드 | 10 | T01~T10에 연결 |

한국어 제목·소개·학습목표·확인질문·용어 정의·예시·도구 실습 순서는 **학습실 작성**이다. 원문 전체 번역이나 저자의 직접 발언으로 표시하지 않는다. 용어의 `sources`와 가이드의 `sources`는 개념·용도 확인 근거이며, 원문 문장을 그대로 옮긴 번역이라는 뜻이 아니다. 확인질문에는 화면에서 ‘학습실 작성’을 표시한다.

자료 URL은 제품 요구사항의 초기 목록을 유지했다. R 자료 20개와 B 자료 6개는 웹 열기로 페이지 응답과 표제·주제를 확인했다. T 자료 10개는 [원본 Excel 카탈로그](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/spreadsh.htm)의 링크·용도를 확인했다. 이 확인은 앱의 다운로드 성공이나 Excel 파일 내부 검증을 뜻하지 않는다.

- R02·R03·R04는 오래된 HTML의 일반적인 문서 제목 대신 실제 본문 표제인 `A Primer on the Time Value of Money`, `A Primer on Statistics`, `Risk Aversion`을 사용했다.
- R06·R07의 원문 페이지 제목은 모두 `Corporate Finance Online Class`다. 한국어 편집 제목으로 실제 금융기초·회계 목록을 구분한다.
- 블로그의 원문 제목을 따로 보존했다. URL의 연월을 발행일 데이터로 자동 변환하지 않으며 과거 사례임을 소개에서 밝힌다.
- 발행일·수정일·가져온 날짜는 정적 seed에 지어 넣지 않는다. 실제 가져오기 결과의 시각·응답을 별도로 저장한다.
- 모든 가이드는 `internalVerified: false`다. 화면에서 ‘파일 내부 입력 위치 미확인’을 표시한다. 입력 항목은 실습 준비 목록이며 파일의 실제 셀 이름·필수 입력칸 목록이 아니다.
- 공식 원문 문제의 답을 학습실이 새로 작성하지 않았다. 문제/해답 관계는 실제 가져오기에서 확인한 링크로 연결한다.

대표 PDF 후보는 R06의 Session 2 ‘The Structure of a Business’에 연결된 [슬라이드](https://www.stern.nyu.edu/~adamodar/pdfiles/FoundationsOnline/slides/session2.pdf)다. 웹 도구에서는 이 PDF 요청이 403으로 실패했다. 표지·발행일·페이지 수는 이 확인만으로 확정하지 않는다. 앱의 실제 가져오기 결과가 별도의 기준이다. 기본 36개 목록은 유지하고, 확인한 첨부 PDF를 추가할 때는 부모 R06과의 관계를 가진 별도 자료로 등록한다.

검증한 내용: TypeScript 실행기로 네 배열을 읽었으며 자료 36개·단원 8개·용어 44개·가이드 10개를 확인했다. 자료/용어 ID 중복이 없고, 단원의 자료·선수용어와 도구 가이드의 자료 연결에 누락이 없다. 운영 DB·개인 기록은 이 콘텐츠 검증에서 사용하지 않았다.

# 금융자료 학습 준비 기준 — 2026-09-11

정책 ID: `learning-readiness-20260911-v1`. 상태: **정책 확정, 새로운 최종 시험·인간 학습 효과 검증은 미실시**. 구조화된 같은 기준은 [JSON](LEARNING_READINESS_BASELINE_20260911.json)에 보존한다.

여기서 baseline은 모델 이름이나 모델 점수가 아니라 **평가 집합, 원문 명제, 허용 오류, 판정 절차로 정의한 최소 수용 기준**이다. 원문과 한국어 번역을 병렬로 읽는 금융 학습실을 대상으로 하며, 모델·가중치·양자화·문맥·프롬프트·용어집·실행 구성별 결과를 각각 보고한다. 더 큰 모델, 높은 자동 점수, 빠른 생성, 경고가 없는 화면은 이 기준의 통과 근거가 아니다.

**평가 표본에서 critical/major 의미 오류 0건을 요구하고, 의미를 보존하는 경미한 표현 차이는 허용한다.** 95% 항목들은 사용자의 높은 정확성 선호, 개념을 잘못 배울 비용, 빨간 경고를 잘못 신뢰할 비용을 고려해 이번에 정한 제품 수용 정책이다. 논문이 입증한 보편적인 안전선이나 “95%면 학습에 문제가 없다”는 보증이 아니다. 사용자에게 모든 지표의 95%를 고집하도록 요구하는 정책도 아니며, 이후 변경은 근거와 새 버전으로 남긴다.

이 문서는 기존 동결 보고서·입력·출력·판정·등록 조건을 소급 수정하지 않는다. 앱 제공자·등록 manifest·운영 DB·학습 가중치를 변경하거나 새 실행을 시작하지 않는다. 학습 데이터 행별 수용은 [학습용 번역 최소 기준](TRAINING_QUALITY_FLOOR.md), 앱 상태·표시 계약은 [제품 요구사항 7.9](../../DAMODARAN_KO_LEARNING_SPEC.md#79-자동-의미-위험-표시--2026-09-11-추가-승인)와 [시스템 설계 8.6](../../SYSTEM_DESIGN.md#86-독립-의미-검사와-프로세스-전환)을 함께 따른다.

## 1. 무엇을 의미 오류로 볼 것인가

번역을 보기 전에 원문과 필요한 이웃 문맥에서 학습 명제를 적는다. 원문이 허용하는 여러 해석, 문장 결합·분리, 한국어 어순과 주어 생략, 동의 표현을 허용하며 참조 번역의 문구를 정답 전체로 취급하지 않는다.

| 판정 | 이 학습실에서의 의미와 처리 |
|---|---|
| critical | 핵심 학습 단위가 목적에 맞지 않게 되거나 중대한 잘못된 적용으로 이어질 오류. 핵심 계산의 분자·분모/연산 방향, 적용 조건·부정의 반전 등이 실제 학습 결론을 바꾸는 경우를 문맥과 영향에 따라 판정한다. 관측 1건이면 해당 집합 탈락 |
| major | 중요한 의미 손실·변경으로 이해·신뢰·사용에 지장을 주는 오역, 누락, 추가, 잘못된 개념 연결. 관측 1건이면 해당 집합 탈락 |
| minor | 의미·핵심 이해를 보존하는 경미한 문체, 표기, 자연스러움 문제. 허용하되 유형·빈도를 기록. 누적되어 이해를 방해하면 영향에 맞춰 다시 판정 |
| neutral | 뜻이 맞는 동의 표현, 평가자의 개인적 선호 차이. 오류로 세지 않음 |
| 보류 | 원문 손상, 부족한 문맥, unresolved 참조, 판정 분쟁, 증거 부족. 통과로 세거나 분모에서 조용히 제외하지 않음 |

critical과 major는 오류 유형의 이름만으로 결정하지 않는다. 같은 조건 누락도 실제 영향에 따라 달라진다. 두 등급의 경계가 다투어져도 둘 다 수용 불가이므로 임의로 minor로 낮추지 않는다. 원문을 근거로 판정을 조정하고, 해결되지 않으면 보류한다. 현재 알려진 필수 경고 6개를 모두 MQM critical로 소급 재분류하지 않는다. MQM 자체도 severity와 합격선을 사용 목적에 맞추도록 한다. [MQM 공식 scoring model](https://www.themqm.org/mqm-pillars/the-mqm-scoring-models/)

검토자는 주체·대상·지급/수취 방향, 부정·수량의 범위, 필요/충분 조건, 의무·가능성·확실성, 숫자·단위·기간·연산 관계, 문맥 속 용어 의미, 대명사·인용·시간 관계, 누락·추가를 확인한다. 숫자 문자열이 그대로여도 나눗셈 방향이 바뀌면 통과하지 않는다. 원문에 없는 계산 결과·보충 설명을 번역 본문에 넣어 이해 질문을 맞추지 않는다.

## 2. 번역 baseline의 수용 gate

모든 필수 gate를 동시에 충족해야 한다. 쉬운 용어·질문을 추가해 비율을 높이거나, 같은 원문의 여러 모델 출력을 합쳐 한 모델의 성능처럼 보고하지 않는다. 원시 정수와 분모를 먼저 제시하며 반올림한 95.0%로 문턱을 넘기지 않는다.

| 지표 | 고정 분모·판정 단위 | 수용선 |
|---|---|---|
| 평가 완결성 | 사전 확정한 해당 집합의 전체 학습 단위 | 생성·무결성·의미 검토 100%, 미완료·미판정·분쟁 0건 |
| critical/major | 해당 모델·구성의 전체 평가 단위. 오류 건수와 오류가 있는 단위 수를 함께 기록 | 각각 0건 |
| 핵심 의미 보존 | 원문에서 사전 정의한 핵심 명제·관계 전체 | 100% |
| 뜻이 맞는 용어 표기 | 사전 주석한 **문맥별 용어 출현 건수** | 올바른 의미와 수용 가능한 한국어 표현을 함께 충족한 출현 ≥95% |
| 번역만으로 질문 답변 가능 | 원문에서 미리 작성·검토한 전체 의미 질문 | ≥95% |
| 핵심 질문 답변 가능 | 그중 핵심 개념·계산·조건 질문 전체 | 100% |

용어 표기는 동의 표현을 허용하고, 동일 단어의 비금융 의미도 문맥대로 인정한다. 용어의 의미를 잘못 옮겨 major가 되면 용어 비율이 95%를 넘더라도 의미 gate에서 탈락한다. 작은 선택 주석에서 12/12를 맞춘 결과는 **그 12개 출현의 결과**이며 금융 용어 전체 정확도가 아니다. 사전 주석 범위·전체 용어 출현을 얼마나 다루었는지·고유 용어 수를 함께 기록한다.

질문 95%도 의미 오류 5%를 허용한다는 뜻이 아니다. 답변 불가능의 원인이 critical/major이면 의미 gate에서 탈락한다. 원문 자체로 답할 수 없거나 모호한 질문은 모델 출력을 보기 전에 고친다. 출력 관측 후 발견한 질문 결함·판정 분쟁은 원래 분모와 보류 건수를 보존하고 해당 gate를 통과로 선언하지 않는다. 새 질문 버전으로 평가할 때는 변경 이유와 별도 결과를 남긴다.

분모가 0이면 100%로 만들지 않는다. 사전 계획상 비해당인 지표는 `not_applicable`, 필요한 자료가 없는 지표는 `not_evaluated`로 기록한다. 필수 gate의 `not_evaluated`·보류가 남으면 전체 수용을 보류한다.

## 3. 질문 평가와 실제 학습 효과의 경계

질문은 원문에 근거한 명제와 정답 근거를 먼저 고정하고 번역 모델에는 전달하지 않는다. 학습 단위마다 가능한 범위에서 핵심 관계, 적용 조건/부정, 계산 또는 여러 문장의 결합·추론을 포함한다. 단순 어휘 재현만으로 학습 이해를 대신하지 않는다.

평가자는 평가 대상 한국어 번역과 사전에 명시한 한국어 학습 문맥만으로 답을 만들고 근거를 표시한다. 영어 원문·참조 번역·다른 후보의 출력을 보고 빠진 의미를 보충하면 “번역만으로 답변 가능”으로 세지 않는다. 채점 단계에서는 원문 명제와 비교하고, 정답의 동의 표현을 인정하되 필요한 조건·주체·단위를 빠뜨리거나 원문에 없는 사실을 더한 답은 해당 기준대로 실패/보류 처리한다.

번역의 이해 질문을 이용한 원논문은 목표 언어 응답, 서술형 답, 문자 그대로의 정보·재조합·추론, 전문 번역 통제군을 사용했다. 동시에 사람의 응답 차이와 질문 난도로 인해 답변 점수를 번역 전체 품질로 환산하기 어렵다는 한계도 보고했다. 독일어→영어 결과이며 금융 한국어의 95% 합격률을 제시하지 않는다. [Scarton & Specia, 2016](https://aclanthology.org/L16-1579/)

도우미가 수행한 질문 대조는 `assistant_answerability_review`다. 사용자 검수나 실제 학습자의 이해·기억·전이 실험으로 바꾸지 않는다. 실제 학습 효과를 측정하려면 한국어 학습자의 사전 지식, 검수 한국어 통제 자료, 즉시 이해 및 이후 적용/기억을 구분하고 번역 때문에 생긴 오개념을 조사해야 한다. 현재 그런 인간 실험은 **미실시**다.

잘못된 서술이 직접 기억뿐 아니라 관련된 잘못된 추론으로 이어질 수 있다는 실험 결과는 핵심 관계와 적용 질문을 포함할 근거다. 다만 영어 허구 이야기·일반 지식 실험에서 나온 결과를 금융 한국어의 오류 발생률이나 안전 합격률로 환산하지 않는다. [Butler·Dennis·Marsh, 2012](https://pubmed.ncbi.nlm.nih.gov/22640369/)

## 4. 자동 위험 경고와 빨간 밑줄은 별도 gate

번역 모델 수용과 위험 감지기 수용은 별개다. 번역 baseline을 통과해도 감지기 성능이 입증되지 않으며, 좋은 감지기가 부정확한 번역을 학습용 완성본으로 만들지도 않는다.

| 향후 gate | 분모·정의 | 수용선 |
|---|---|---|
| 문단 위험 재현율 | TP / (TP + FN). 정답상 major 또는 critical이 있는 문단별 출력 중 빨강·주황 위험 경고가 나온 수 | ≥95% |
| 경고 정밀도 | TP / (TP + FP). 빨강·주황 위험 경고가 나온 전체 문단별 출력 중 실제 major/critical이 있는 수 | ≥95% |
| 기지 핵심 사례 | 동결된 필수 오류 출력 6개 중 위험 경고 수 | 6/6 |
| 빨간 구간 의미 정확성 | 실제 제시한 전체 빨간 한국어 구간 중 위치·원인·범위를 올바르게 짚은 구간 수 | ≥95% |
| offset 기술 유효성 | 감지기가 제출한 한국어·영어 offset 전체 중 UTF-16 범위·substring·surrogate 경계 검증 통과 수. 표시 전에 거부한 구간도 분모에 포함 | 100% |

문단 TP는 해당 문단의 위험 탐지이며 모든 오류를 찾았거나 원인을 맞혔다는 뜻이 아니다. 오류 유형·severity별 누락, 오류별 탐지 범위, 구간을 제공한 비율을 별도로 기록한다. 문단의 한 오류를 찾았다는 이유로 그 안의 모든 오류를 탐지했다고 세지 않는다.

빨간 구간의 정답은 검토자가 원문·번역 근거로 확정한 허용 구간이다. 단순한 겹침, 오류와 무관한 정상 문맥까지 포함한 과도한 문단 전체 밑줄, 엉뚱한 이유는 적중으로 세지 않는다. 한국어 표현의 차이를 허용할 수 있는 경계 규칙을 출력 관측 전에 고정하며, 판정 분쟁은 보류한다. 같은 경고 구간의 중복 제시는 별도 적중으로 늘리지 않는다. **기술적으로 유효한 offset도 의미상 맞는 구간이라는 보증은 아니다.** 렌더링 전 기술 검증은 항상 수행하고 거부된 구간 수·이유도 보고하며, 거부한 구간을 감지기의 기술 정확도 분모에서 제거하지 않는다.

미설치·실패·취소·길이 초과·보류는 정상 판정으로 세지 않는다. 전체 시도 수, 완료 수, 미평가 수와 원인을 함께 보고한다. 고정 평가 집합의 오류 문단에서 탐지 결과가 없으면 종단간 재현율의 FN으로 계산하고, 동시에 감지 실행 실패임을 표시한다. 성공 응답만 고른 조건부 지표는 따로 표시하며 수용 gate를 대신하지 않는다.

오류 구간을 모르는 낮은 문단 점수는 주황 문단 경고로만 표시한다. 빨간 밑줄이나 정밀한 영어 구절 정렬을 만들어 내지 않는다. 영어는 연결된 실제 문장 전체를 보여준다. 빨간 구간이 0개이면 구간 정확도는 `not_evaluated`이며 100%가 아니다. 문단 gate를 통과해도 빨간 구간 gate를 자동 통과한 것으로 표시하지 않는다. 구간 없는 누락 등 국소화할 수 없는 사례의 수와 이유도 남긴다.

경고 정밀도 95%는 실제 경고 중 최대 약 5%의 오경고를 허용하는 정책상 목표이고, 재현율 95%는 실제 오류를 놓치지 않기 위한 별도 목표다. 두 수치가 동시에 가능한 후보가 없으면 미충족으로 남긴다. 정밀도는 오류 유병률에 영향을 받으므로 실제 사용에 가까운 표본과 인위적 오류 도전셋을 분리하고 전체 경고율도 보고한다. 거의 모든 문단을 경고해 재현율만 높인 결과를 채택하지 않는다.

전체 평균 외에 **번역 모델·구성별, 원문 집합별(dev/reading 등), 실제 관측된 모델·구성 × 원문 집합 교차 집합별** 재현율·정밀도도 각각 95% 이상이어야 한다. 쉬운 집합이 다른 집합의 실패를 상쇄하지 않는다. 양성 정답이 0개라 재현율 분모가 없거나 경고가 0개라 정밀도 분모가 없으면 `not_evaluated`이며 100% 통과가 아니다. 필요한 하위 집합의 근거가 없으면 추가 평가 전 수용을 보류한다. 각 하위 집합의 분모와 실제 오류 분포를 함께 보고한다.

경고 신뢰도를 달리한 138명 대학생의 실험에서는 다수가 실제 경고 확률에 맞추어 반응 빈도를 조절했다. 오경고 부담을 측정할 근거지만 항공 경고를 모사한 이중 과제였으며, 교육용 reader나 “95/95”의 타당성을 실증한 연구는 아니다. [Bliss·Gilson·Deaton, 1995](https://pubmed.ncbi.nlm.nih.gov/7498189/)

**기존 QE 실험의 사전 조건과 당시 판정은 불변**이다. [로컬 QE 기록](../../scripts/local-qe/README.md)의 재현율 ≥85%, 정밀도 ≥60%, 경고율 ≤50%, 기지 사례 6/6 조건과 그 원본 산출물은 보존한다. 향후 신규 등록 코드는 별도 제품 정책 `product-qe-95-v2`를 적용한다. 정책 파일 경로는 `scripts/local-qe/policy-product-95-v2.json`이며 전체와 위 하위 집합의 95/95 조건을 구분한다. 전체 평균만 보던 제품 정책 v1도 역사 기록으로 보존하고 v2와 혼동하지 않는다. 이 문서 작성 자체는 그 코드 변경이나 신규 등록을 수행하지 않으며, 현재 구현·실행 여부는 로컬 QE 기록에서 확인한다.

이 문서의 95/95·구간 기준은 이후 후보를 위한 새 정책이며 과거 실패를 성공으로 바꾸지 않는다. 현재 구형 COMET-QE 실측의 45/48 경고·14/45 정밀도는 기존 gate부터 실패했고, 이 문서도 등록 승인을 만들지 않는다. 문단 판정만 하는 제품 등록 정책을 통과하더라도 빨간 구간 기준까지 통과했다고 주장하지 않는다.

필수 6개는 `LDEV26-008`의 equity 뜻 오류 2개, `REAL26-004`의 Treasury bills 만기 구분 오류 2개, `REAL26-005`의 나눗셈 반전 1개, `REAL26-006`의 영구 성장 조건 누락 1개다. 정확한 출력 식별은 동결 QE 입력·판정 manifest에 따른다.

## 5. 평가 집합과 새로운 시험 계획

| 집합 | 용도와 수용 판단 |

| [dev18](linguistic-dev-20260910.jsonl) | 이미 사용한 개발 회귀. 모델·구성별 18/18 완료 검토와 critical/major 각각 0건 요구 |
| [reading6](real-reading-check-20260910/dataset-manifest.json) | 실제 공개 읽기 원문 6개 회귀. 현재 하나의 자료에서 뽑은 작은 집합이며 별도로 critical/major 각각 0건 요구 |
| [general16](general-context-dev-20260911-manifest.json) | 일반 문맥·다의어·지시 회귀. 별도로 16/16과 critical/major 각각 0건 요구. 금융 용어 성능과 합산하지 않음 |

| fresh60 + 의미 질문 | **향후 계획, 미실시.** 모델 선택·구성·평가 규칙을 고정한 뒤 새 금융 학습 단위 최소 60개와 사전 의미 질문을 준비·검토·동결하고 한 번의 새 검증으로 사용 |

새 최종 시험에서는 개념 정의, 인과/비교, 조건/부정, 계산/수량, 여러 문장 연결을 사전 배분한다. 원문 문서·문맥 단위로 표집·분할하며 다른 추출 버전·인접 문단·숫자만 바꾼 문장·근접중복도 같은 그룹으로 다룬다. 출처별 문서 수·학습 단위 수와 영역·길이 분포를 보고한다. 현재 초기 의미 검사 범위 밖인 표는 별도 평가 없이 지원을 주장하지 않는다.

QE의 향후 calibration과 holdout은 **원문 그룹 단위**로 나누어 같은 원문의 다른 모델 출력이 양쪽으로 새지 않게 한다. 이미 전부 관측한 QE48을 사후로 나누어 새 독립 holdout이라고 부르지 않는다. 임계값은 calibration에서만 선택하고 고정한 뒤 새 holdout에 적용한다. 기지 핵심 6개는 별도 필수 회귀이며 새 holdout 표본 수에 합산하지 않는다. 번역 모델의 fresh60과 감지기의 오류 포함 holdout은 목적·분모가 다르며, 번역 오류가 0인 집합으로 감지 재현율을 검증할 수 없다.

새 시험 실패 후 같은 시험을 보며 설정·학습을 조정하면 그 집합은 개발 자료가 된다. 기존 결과와 정책을 보존하고 다시 독립된 시험을 계획한다. 쉬운 일반 문장, 여러 모델 출력, 반복 질문 수를 합쳐 독립 금융 원문 수를 부풀리지 않는다.

## 6. 표본 크기가 허용하는 결론

독립·동일 분포의 이항 시행으로 목표 분포에서 뽑은 표본이라는 가정에서, 오류 0/n일 때 오류율의 단측 95% 신뢰상한은 `1 - 0.05^(1/n)`이며 약 `3/n`이다. 이 신뢰수준 95%는 앞의 성능 수용선 95%와 다른 개념이다. [Hanley & Lippman-Hand, 1983](https://jhanley.biostat.mcgill.ca/c607/ch08/zero_numerator.pdf)

| 가정상 독립 표본 n | 관측 오류 | 단측 95% 오류율 상한 |
|---|---|---|
| 6 | 0 | 약 39.30% |
| 18 | 0 | 약 15.33% |
| 24 | 0 | 약 11.73% |
| 60 | 0 | 약 4.87% |

**60개에서 오류 0건이어도 실제 오류율 0이나 무오류 학습을 보장하지 않는다.** 동일 문서의 연속 문단, 같은 원문의 두 모델 출력, 도우미 선택 사례는 독립성·대표성 가정을 만족한다고 단정할 수 없다. 그러한 조건을 확인하지 못하면 위 상한을 전체 금융자료에 일반화하지 않는다. 표본·판정의 편향은 이 계산으로 사라지지 않는다.

오류 정답이 14개뿐인 평가에서 14개 모두 찾았더라도, 같은 가정에서 재현율의 단측 95% 하한은 약 80.74%다. 작은 표본의 관측 재현율 100%를 안정적인 95% 성능 보장으로 표시하지 않는다. 모든 비율에 원수와 신뢰구간·표집 가정을 남기며, 생성에 실패해 완료 출력이 0개인 실행을 의미 오류 0건 통과로 읽지 않는다.

## 7. 기록과 통과 표현

각 결과에는 정책 ID, 집합/원문/문맥/명제/질문 해시, 모델 revision·가중치·양자화·실행/프롬프트/용어집 정체성, 생성·검토 완료 수, severity별 오류와 보류, 용어·질문 분자/분모, 경고 혼동행렬·coverage·구간 평가, 검토자 종류·근거·조정 이력, 인간 검수 여부를 남긴다. 도우미끼리 합의해도 `humanReviewed=false`를 유지한다. 현재 정책 문서는 모델별 수용 결과를 만들지 않는다.

“도우미 대조에서 해당 고정 표본의 critical/major 0건”과 “새 독립 시험 통과”, “사용자 검수 완료”, “실제 학습자 효과 측정”을 각각 구분한다. 자동 의미 검사 미설치·실패·경고 없음은 학습 안전 판정이 아니다. 평가 분쟁이나 필수 미평가가 남은 결과는 보류이며, 모델이 큰 점수로 보완하거나 평균 점수로 상쇄하지 않는다.

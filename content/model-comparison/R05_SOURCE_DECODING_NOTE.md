# R05 원문 디코딩 조사 메모

R05의 저장 원문에서 발견한 U+FFFD 대체문자는 **16개 문단의 정확히 23개**다. 보존 HTML의 `macintosh` 선언에 따라 읽으면 따옴표·아포스트로피로 복원되며, 이 문자들 외 차이는 없다. 이번 조사는 도우미의 읽기 전용 대조이며 사람 검수가 아니다.

증거는 [상세 JSON](../../.training/verifications/r05-source-decoding-audit-20260910.json)에 저장했다. 블록별 ID·순서·저장 원문 SHA·재현 원문 SHA와 23개 문자 각각의 위치를 포함한다.

- 대상: R05, 원문 버전 `6c868b56-d0f7-45f5-8863-50b6de627ec3`, `structured-v2`.
- 보존 파일: [원본 HTML](../../data/originals/a84827747e46ba5fd4709354419fe5a6359658b450f582d8c826652b89261ff1.html), 120589바이트.
- 원본 SHA-256: `a84827747e46ba5fd4709354419fe5a6359658b450f582d8c826652b89261ff1`.
- 저장 원문 블록 스냅샷 SHA-256: `dde7f6d994bb3c138b15fd5124fe63b2ffb8d3abe5d6d7562cdc2da70031a864`. 블록 181개의 `id/sortOrder/type/sourceSha256` 순서 배열을 UTF-8 `JSON.stringify`로 직렬화한 값이다.
- 저장 출처: NYU의 `New_Home_Page/background/valintro.htm`; 저장 시각 `2026-09-09T05:10:30.879Z`. 이번 조사에서 HTTP 재요청은 하지 않았다.

보존 바이트에는 U+FFFD의 UTF-8 바이트열이나 대체문자 HTML 엔터티가 없다. 현재 추출 코드에 UTF-8을 명시하면 저장된 181개 블록의 원문 전체와 정확히 일치한다. 반면 HTML meta의 Macintosh 선언을 따르면 165개 블록은 그대로이고 나머지 16개 문단에서 아래 문자만 달라진다.

| 원본 바이트 | 저장된 문자 | Macintosh로 읽은 문자 | 개수 |
|---|---|---|---:|
| D2 | U+FFFD | “ (U+201C) | 4 |
| D3 | U+FFFD | ” (U+201D) | 5 |
| D5 | U+FFFD | ’ (U+2019) | 14 |
| 합계 | | | 23 |

블록별 숫자·부호·백분율 토큰의 다중집합과 **모든 ASCII 문자 순서가 동일**하다. 이번 디코딩 차이에서 숫자·통화 기호·부호의 손실은 관측되지 않았다. 금융 용어의 ASCII 철자도 보존되었다. 다만 인용 경계와 `market’s`, `firm’s`, `asset’s`, `model’s` 같은 소유 관계가 손상되어 누가 한 말인지, 무엇의 가치·산출물인지 읽는 데 영향을 준다. 이 검사는 원문 전체의 수량 의미나 번역 품질에 대한 보증은 아니다.

**당시 실제 HTTP charset은 알 수 없다.** 현재 코드는 HTTP charset을 HTML meta보다 우선하지만 DB에는 정규화된 `mime=text/html`만 남아 있다. 저장 원문이 현재의 강제 UTF-8 경로와 완전히 일치함은 확인했으나, 당시 서버가 UTF-8을 선언했는지와 정확한 역사적 실행 경로까지 확정하지 않는다. 코드 경로와 조사 시점 코드 SHA는 상세 JSON에 결속했다.

저장 상태가 `ready`이고 경고가 비어 있어도 올바른 원문 해독을 뜻하지 않는다. Windows-1252로 읽어도 U+FFFD는 0개지만 해당 바이트가 Ò·Ó·Õ가 된다. 따라서 대체문자 수만을 원문 정상화의 성공 기준으로 삼을 수 없다.

현재 `real-reading-check-20260910`에서는 R05를 제외했다. 인용·소유 관계를 읽을 수 있는 원문 확보가 학습용 번역의 의미 보존 평가에 앞서야 하며, 손상된 입력을 포함하면 디코딩 결함과 모델 오류를 분리하기 어렵기 때문이다. 모델 출력이나 점수를 보고 제외한 것이 아니다.

코드·DB·원본·저장 블록·번역은 변경하지 않았고 번역 결과나 개인 기록은 읽지 않았다. 6개 이미지 내용과 다른 자료·버전은 조사하지 않았다. 향후 교정은 별도 작업에서 새 원문 버전으로 다루며 기존 원본·블록·번역·개인 기록을 보존해야 한다.

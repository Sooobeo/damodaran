# 공통 입력 처리 개발 비교 결과 — 2026-09-20

## 결론

S4 번역 생성과 S5 원문·질문 평가를 완료했다. [S1 계약의 고정 선택 기준](../input-preparation-v1/CONTRACT.md)에 따른 결론은 **`retain_registered_configuration` — 기존 등록 유지**다. C1·C3는 일부 원문 지표가 개선됐지만 일반 질문 회귀가 있어 탈락했고, C2는 필수 개발 개선이 없었다. 적격 후보가 없으므로 S6의 독립80단위 확대평가·신규 등록·앱 교체는 시작하지 않는다. 이는 기존 구성이 모든 품질 기준을 통과했다는 뜻이 아니다.

현재 앱 등록 `hymt-contextual-q26-20260910-nativejob`와 운영 DB·원문 버전·개인 기록을 유지한다. 이번 비교에서는 가중치 재학습이나 유료 API 호출을 하지 않았다. 선택 기준과 질문·답변을 결과에 맞춰 수정하지 않았다.

## 평가 범위와 결과

개발 원문은16단위(금융8·일반8)이며, 같은 원문을 C0~C3으로 비교한64출력이다. **독립 원문64개가 아니다.** 원문 검토64개, 핵심 명제192개, 용어 출현156개, 질문128개(핵심64개)를 모두 평가했고 미해결은0이다. 질문 정답117/128, 오답11/128, 핵심 질문 정답54/64다. 합계는 이 개발 비교의 관측값이며 일반 번역 정확도나 실제 학습 효과를 뜻하지 않는다.

중요 오류 단위는 원문 대조의 major/critical 판정이다. 경미 오류는 C0·C1·C2·C3 각각4·3·4·2단위였다. 지표 간 상쇄로 후보를 통과시키지 않는다.

- C1: F04에서 C0가 보존한 핵심 명제 하나가 손상됐다. G06 질문1에서는 나눗셈 방향은 맞지만 결과 단위에서 ‘파일당’을 빠뜨렸다.
- C2: 중요 오류 단위나 핵심 명제에 필수 개선이 없다. 자연스러움 합계 차이만으로 채택하지 않는다.

G06의 C1·C3 번역은 원문 검토상 핵심 명제3/3을 보존했다. 그 번역을 읽은 Qwen 질문 답변의 누락을 **새 번역 오류로 가산하지 않는다.** 이번 질문 평가는 고정된 단일 답변 절차의 관측이며 모델 내부 원인이나 사람의 학습 효과를 입증하지 않는다. 후속 실험에서 이 한계를 검토할 수 있지만 이번 답변의 재생성·사후 채점 기준 완화·후보 재선정은 하지 않는다.

[S2 실제 입력 준비 결과](../input-preparation-v1-s2s3/README.md)에서 이번16단위의 새 사전 금융 힌트는0개였고, C2/C3의 사전 차이는 F02/F04의 기존3힌트 제거에 한정됐다. 따라서 새 금융 뜻 선택의 일반적인 효능을 주장하지 않는다.

## 생성·동결·채점 증거

원래 질문 실행의 완료9개와 실패 상태를 그대로 보존했다. memory-v6로 나머지55개를 한 번씩 생성했으며, 원9+새55의64문맥/128답변을 수집·동결한 뒤 세 도우미가 원문을 대조해 채점했다. 각 질문 답변은 별도 소유 Qwen native 프로세스에서 한국어 번역·질문만 보고 작성했다. 원문 채점자는 이 답변자가 아니며 모든 검토는 `humanReviewed=false`다. 정확한 채점 모델 runtime ID가 노출되지 않는 한계도 영수증에 명시했다.

질문 답변 오답11개는 상대%/%p 혼동4개, 필수조건 반전4개, 계산 요소·단위 누락2개, 명시된 관점에 대한 답변 실패1개다. 애매한7문항은 별도 도우미가 원문·고정질문·최종 답변·초안을 교차 대조해 판정과 인용의 일치를 확인했다. ## 원장·자원·남은 제약

원장 준비와 실제 추가 모두 exit0으로 완료했다. [준비 영수증](../../../.training/quality-evaluation/input-preparation-v1/s5-ledger-prepared-memory-v6-20260920/prepared-manifest.json)은 기존836사건과 번역 검토146개를 대조했다. [실제 추가 영수증](../../../.training/quality-evaluation/input-preparation-v1/s5-ledger-appended-memory-v6-20260920/append-receipt.json)은 관측128개(input64·relation64) 추가·재사용0, 전체836→964사건, `allPriorEventBytesUnchanged:true`, 번역 검토146개 보존·신규 번역 검토0을 기록한다. 추가 영수증 SHA는 `8657e7536aa326522a59c8ebdaa9b76fd2fdb325861b814794201eded0f21ba4`다. 질문 오답과 관계 경고를 별도 번역 오류로 추정하지 않았고, 원래 실패 실행을 성공으로 바꾸지 않았다.

새55개 생성은6,976.698초가 걸렸으며 모든 소유 native 프로세스 종료와 임시 전원 요청 해제를 확인했다. [채점 중 캐시 점검](../../../.training/verifications/question-memory-v6-postgrading-resource-snapshot-20260920.json)의 조사 범위에서 새 `.pyc`는0개이며 빈 캐시 폴더는 보존했다. 활성 채점 Python의 launcher·자식 구분은 [후속 프로세스 트리 점검](../../../.training/verifications/question-memory-v6-postgrading-resource-followup-20260920.json)에서 보완했다. 디스크 캐시 삭제를 RAM 확보량으로 표현하지 않는다.

이번 후속 작업은 개발 비교의 완료이지 번역 모델 전체 품질 수용이나 신규 배포 완료가 아니다. 독립 holdout, 사람 검수, 실제 학습 효과는 검증하지 않았다. 앱 코드를 바꾸지 않았고 앱 build/E2E·실제 HTML3문단/PDF1페이지의 앱 생성·저장·캐시 검증도 새로 실행하지 않았다. 가중치 재학습·질문 평가 도구 개선·새 후보 실험은 별도 가설과 독립 자료를 갖춘 후속 작업이며, 소비한 개발/시험 결과를 숨기거나 같은 평가를 통과할 때까지 재조정하지 않는다.

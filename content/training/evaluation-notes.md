# 독립 번역 평가 문장 — 고정된 test 분할

이 문장쌍은 최종 번역 평가용 `test` 분할이다. 금융 40개와 일반 문장 20개를 모델 출력을 보지 않고 독립적으로 작성했다. 영어 원문과 한국어 기준 번역은 모두 도우미가 직접 작성했으며, 실제 Damodaran 문장을 복사하거나 사용자 메모·검수문을 가져오지 않았다. **전문가 또는 사용자가 검수한 정답이 아니다.**

각 행의 `provenance`는 `assistant-authored evaluation; not user-reviewed`, `split`은 `test`로 고정한다. 모델 가중치 학습, 데이터 증강의 예문, 용어 치환 규칙 보완, 조기 종료, 하이퍼파라미터 조정 또는 체크포인트 선택에 이 파일을 사용하지 않는다. 모델 선택과 학습 중 확인에는 별도의 `dev` 분할을 사용한다. 최종 후보를 확정한 뒤 같은 입력·출력 설정으로 기본 모델과 학습 모델을 비교한다.

금융 문장은 [금융 번역 용어 규칙](../translation-glossary.json)의 한국어 표기를 사용한다. `terms`에는 해당 영어 원문에 실제로 등장하는 표현과 기준 번역에 포함된 한국어 표기를 기록한다. 복수형·하이픈 등은 사전의 명시적 별칭을 따른다. 용어 일치율은 용어 표기의 보존 지표일 뿐 문장 의미 전체의 정확도는 아니다.

평가 범위는 재무 보고 범위, 이익과 현금의 차이, 운전자본, 지급 시점, 할인율, 자본비용, 차입 효과, FCFF·FCFE, 성장과 재투자, 계속가치, 가치와 가격, 배수, 사업별 베타다. 조건·부정·원인·기간과 비교 대상을 구분하도록 다양한 문장 구조를 사용했다. 일반 문장은 금융과 무관한 박물관·언어·여행·요리·식물·소포·음악·관측·날씨 등으로 구성하며, `return`, `interest`, `capital`, `spread`, `primer` 같은 다의어가 금융 의미로 바뀌는지도 확인할 수 있다.

영문 길이는 공백 기준 단어 수로 확인한다. 숫자, 통화 기호와 코드, 백분율, `°C`, `cm`는 기준 번역에서도 보존한다. 자동 평가에서는 금융/일반 문장별 결과를 따로 제시하고, 용어 일치율·숫자 보존·번역 유사도와 의미 검토를 구분한다. 단일 기준 번역과 작은 도우미 작성 표본이므로 일반적인 전문 번역 품질을 보장하는 근거로 사용하지 않는다.

작성자는 학습·개발 문장쌍을 읽지 않고 이 파일을 작성했다. 학습 담당자에게 평가 주제만 먼저 전달했다. 최종 고정 전에 분할 간 정확 중복과 숫자만 다른 문장, 높은 어휘·문자 유사도를 원문을 출력하지 않는 스크립트로 확인했다. 고정 후 기준 번역을 모델 출력에 맞춰 수정하지 않는다. 학습·개발 분할이 바뀌면 중복 검사를 다시 하고, 겹치는 항목은 학습·개발 쪽에서 제거한다. 명백한 평가 데이터 결함을 나중에 발견하면 해당 결과에 결함을 명시하고 별도 버전·새 평가 계획을 사용하며 현재 파일을 덮어쓰지 않는다.

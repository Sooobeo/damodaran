# 영한 금융 번역 소규모 학습 데이터

현재 앱에서 실제 사용자가 검수한 영한 문장쌍은 0개인 상태에서 시작했다. 이 디렉터리의 `train.jsonl`과 `dev.jsonl`은 실제 모델 가중치의 소규모 추가 학습을 위해 어시스턴트가 독자 작성한 보조 데이터다. 기존 47개 용어 규칙을 문장 번역 실험으로 확장하되, 다모다란 원문 문장을 모아 번역한 자료나 사용자 검수 번역으로 표시하지 않는다.

| 파일 | 개수 | 용도 |
|---|---:|---|
| `train.jsonl` | 200 | 금융 160쌍 + 일반 문장 40쌍, 가중치 학습 |
| `dev.jsonl` | 40 | 금융 30쌍 + 일반 문장 10쌍, 모델·체크포인트 선택과 일반 번역 유지 확인 |
| `metadata.json` | — | 개념 출처 URL, 구성, 작성 방식, 파일 해시, 확인한 접근 조건 |

독립 평가용 test는 다른 작성자가 train/dev 문장을 읽지 않고 별도로 만든다. test를 학습이나 반복적인 모델 선택에 넣지 않는다. 최종 성능은 실제 실행 결과를 별도 보고하며, 데이터 작성만으로 번역 성능이 향상됐다고 주장하지 않는다.

## 작성 기준

금융 160쌍은 재무제표, 화폐의 시간가치, 위험, 할인율, 현금흐름, 성장, 상대가치, 가치평가 판단의 8개 영역에 각각 20쌍씩 배분했다. 정의만 반복하지 않고 원인, 조건, 비교, 부정, 보고서 읽기, 가상 수치 예시를 섞었다. 일반 문장 40쌍은 작업실·문서·장치·수업 등 다른 문맥을 담았다. `return`, `capital`, `primer`처럼 문맥에 따라 뜻이 달라지는 일반어도 포함한다.

영어와 한국어 모두 어시스턴트가 작성했다. 모든 행에 `provenance: "assistant-authored training; not user-reviewed"`를 기록한다. 이는 독립적인 사람의 검수나 전문 번역가의 참조 번역이 아니다. 한국어 표현은 다모다란의 공식 번역이 아니다. 숫자는 설명용 가상 값이며 특정 기업의 실제 실적으로 제시하지 않는다.

`terms`에는 원문과 번역에 실제로 나타나는 영한 표현만 담는다. 겹치는 복합어는 긴 표현을 우선한다. 예를 들어 순현재가치를 하나의 용어로 다루고 그 안의 현재가치를 별도로 중복 표시하지 않는다. 학습 금융 문장에는 기존 47개 용어·제목이 모두 최소 1회 포함된다. 일반 문장은 `domain: "general"`이고 `terms`는 빈 배열이다.

dev의 금융 30쌍은 감사, 문서 대조, 검토 의견이라는 별도 문장 구조로 작성했다. 일반 10쌍은 장치 고장 재현, 양식, 의사소통, 검토 등의 상황을 새로 작성하여 모델 선택 단계부터 일반 번역의 악화를 살펴볼 수 있게 했다. train의 숫자나 회사 이름만 바꿔 평가 자료로 쓰지 않는다. 그럼에도 합성 문장 사이에는 개념과 문체의 공통점이 있으므로 완전히 독립적인 실제 문서 평가를 대신할 수 없다.

## 작성 후 확인

- 240개 행의 JSON 형식, 고유 ID, split, 실제 영한 용어 구간을 확인했다.
- 240개 행 모두 원문·번역의 숫자와 명시적 통화 코드 토큰이 일치한다. 문장 구조가 달라져 순서는 달라도 토큰별 개수는 보존한다.
- train/dev 사이 정규화된 원문의 완전 중복은 없다. 숫자를 같은 표식으로 바꾸고 영어 단어 집합의 Jaccard 유사도를 계산했을 때 최대값은 0.4였다. train 내부에서 0.6 이상인 문장쌍은 없었다. 이는 의미 중복이나 사전학습 노출이 없다는 증명은 아니다.
- 개념, 부정, 시간 기준, 주주·기업 현금흐름 구분을 작성자가 재검토했다. 독립 전문가 검수는 하지 않았다.

## 공개 병렬 자료 조사

당장 학습할 수 있는 데이터와 공개 소개 페이지만 확인한 자료를 구분했다. 다음 자료의 본문을 학습 데이터에 넣거나 대규모 내려받기를 실행하지 않았다. 정확한 다운로드 바이트 수는 확인하지 않아 metadata에 `null`로 남겼다.

- [AIHub 전문분야 한영 말뭉치](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=111): 전체 150만 문장, 금융·증시 20만 문장으로 안내한다. 내국인 신청과 다운로드 승인이 필요하다.
- [AIHub 사회과학 한영 말뭉치](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=125): 전체 150만, 경제 분야 목표 30만 중 금융 목표 68,000문장이다. 실제 금융 파일의 건수는 확인하지 않았다. 문장별 `source`와 `license` 필드가 있으므로 승인 후 조건과 출처를 보존하여 선별할 수 있다. [AIHub 이용약관](https://aihub.or.kr/useStplat.do?currMenu=110&topMenu=110)과 실제 데이터 조건을 함께 확인해야 하며 공개 소개를 무제한 재배포 허가로 해석하지 않는다.
- [한국은행 경제금융용어 800선](https://www.bok.or.kr/portal/bbs/B0000249/view.do?menuNo=200765&nttId=10096081): 2026년 개정된 한국어 용어 설명 자료이며 완전한 영한 병렬 문장집으로 확인되지 않았다.
- [한국은행 통화신용정책보고서 영문판, 2025년 3월](https://www.bok.or.kr/eng/bbs/E0000628/view.do?depth=400215&menuNo=400215&nttId=10091096&oldMenuNo=400007&programType=newsDataEng&relate=Y): 한국어 2025.03.13판의 영문 번역임을 명시하여 정렬 후보가 될 수 있다. 다만 [한국은행 저작권보호방침](https://www.bok.or.kr/portal/main/contents.do?menuNo=200228)은 제공 공공데이터와 그 밖의 자료를 구분한다. 공개 열람 가능성만으로 학습 이용 조건이 해결됐다고 판단하지 않아 이번 데이터에는 넣지 않았다.

개념 참고는 기존 다모다란 용어집·정의·회계 입문·현재가치 입문·FCFF 설명을 사용했고 각 URL을 `metadata.json`에 남겼다. 출처의 장문을 복사하지 않았으며, 인용된 짧은 제목을 제외한 문장은 이 실험을 위해 새로 작성했다. 추후 실제 검수쌍이나 승인된 병렬 자료를 추가할 때도 이 합성 데이터와 provenance를 구분한다.

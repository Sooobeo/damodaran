# 금융 용어 표기 90% 목표

사용자의 최신 목표는 금융 용어의 기준 표기 적중 90% 이상이며, 금융·일반 문맥에서 뜻이 달라지는 표현을 구분하는 것이다. **본학습 1,728회 갱신을 완료했고 독립 최종 시험에서 용어 103/110(93.64%)로 사전 기준을 통과**했다. 그러나 익명 도우미 대조에서 실질적인 의미 오류가 50/140행에 남아 앱 기본 모델로 선택하지 않았다. 용어 점수를 문장 전체 의미 정확도로 해석하지 않는다.

본학습 진행 중 사용자가 무료 로컬 모델만으로 현재 PC에서 번역 전체를 최고 품질로 개선하고 싶다고 확정했다. 용어 90%는 중간 목표로 유지하고 의미·부정/조건·문맥별 뜻·수량/수식·누락/추가·자연스러움을 별도로 대조한다. 이 요구로 이미 고정한 v5 데이터·학습 조건·통과 기준을 바꾸지는 않는다. 추가 로컬 모델과 앱의 문맥 처리도 검토하며, v5의 짧은 도우미 작성 평가에서 얻은 점수를 실제 모든 금융 문서의 번역 정확도로 일반화하지 않는다.

## 사전 기준과 독립성

기존 앱 학습 사전 44개와 추가 번역 규칙을 통합한 54개 영한 기준 표기를 먼저 고정했다. 카탈로그 SHA-256은 `d4af6a9fed8c6dba4c528abc52c64c19621c5fac98fd2bdb09e035769963de67`다. 복합 용어 안에 포함된 짧은 용어는 중복 주석하지 않으며, 별도 위치에 등장하는 용어는 함께 주석한다. 같은 행의 같은 용어는 한 번만 집계하고 기존 `normalized_term`의 유니코드 정규화·대소문자 통일·공백/구두점 제거 규칙을 그대로 사용한다. 같은 한국어 목표의 중복 제거도 기존 평가 함수에 따른다. 출력 확인 후 동의어를 추가하지 않는다.

새 dev/test는 각각 금융 108쌍(54개 기준 용어가 주 용어로 2회씩)과 일반 32쌍을 계획했다. 일반 영역에는 비금융 다의어 문맥 16개와 금지할 금융 번역 주석이 포함된다. 단어의 초점 뜻과 문장 전체 의미 보존은 별도로 대조한다. 자료는 도우미 독자 작성이며 사람 검수본이나 실제 원문 번역으로 표시하지 않는다. 이전 실험의 실제 원문 train은 출처를 보존해 재사용하지만, v4 test·과거 소비한 진단 문장을 새 학습에 넣지 않는다.

이전 v4의 60/102(58.82%)와 새 54개 용어 범위의 점수는 서로 다른 시험의 결과다. 새 시험은 도우미 작성 문맥 자료에서의 용어 표기 평가이며 실제 전체 금융 문서 번역 정확도를 뜻하지 않는다. 기준 번역과 학습·평가 원문은 Git/public에서 제외한 `.training/datasets/finance-v5/`에 보관한다.

## 실행과 판정

원본은 `Helsinki-NLP/opus-mt-tc-big-en-ko`, revision `ae8606b7b29a495f31ce679cee2007f536a3a5ce`다. v5는 v4의 dev 선택 step 218 FP32 가중치 `feff4d684e52e5d7cae7eccc0bf19316687159169e5c766aa03de73e5dc40a1e`에서 이어 학습한다. 원본 lineage와 부모 모델·토크나이저·코드·설정·데이터 해시를 별도로 고정한다. 기존 `train.py`와 v4 모델·시험·평가 코드는 바꾸지 않는다.

사전 통과 기준은 금융 용어 적중 절대 90% 이상 및 부모 모델 대비 회귀 없음, 숫자·일반 문장 유지, 빈 출력/생성 상한 없음, 일반 문맥의 주석된 금지 금융 표현 출현 0개다. v4의 상대 5%p 기준을 소급 수정한 것이 아니라 새로운 절대 목표에 따른 v5 기준이다. dev로 선택하고 통과한 경우에만 새로운 test를 한 번 소비한다. 학습 가중치 변화와 optimizer 갱신을 기록하며 사후 용어 치환이나 번역 메모리를 점수에 사용하지 않는다.

PowerShell 공통 인자는 첫 validate부터 동일하게 사용한다.

```powershell
$v5Args = @('--run-id','finance-v5-terminology','--device','xpu','--precision','fp32','--epochs','6','--batch-size','1','--accumulation','4','--learning-rate','1e-5','--warmup-updates','5','--max-length','384','--max-new-tokens','384','--beams','4','--seed','20260910','--threads','4','--checkpoint-every','50','--max-updates','0')
.venv-training/Scripts/python.exe -X utf8 -u scripts/model-training/train_v5.py validate @v5Args
.venv-training/Scripts/python.exe -X utf8 -u scripts/model-training/train_v5.py bench @v5Args
.venv-training/Scripts/python.exe -X utf8 -u scripts/model-training/train_v5.py train @v5Args
```

중단된 본학습은 같은 train 명령에 `--resume`을 붙인다. dev가 통과한 뒤에만 다음 명령을 실행한다.

```powershell
.venv-training/Scripts/python.exe -X utf8 -u scripts/model-training/train_v5.py evaluate @v5Args
```

학습을 마친 모델의 별도 FP32 추론에는 v5 부모 lineage와 완료 inventory를 검증하는 다음 CLI를 사용한다. 동결한 `infer_v5.py`는 정상적인 특수 토큰 저장 형식 차이까지 거부하는 제한이 있어, 해당 파일을 바꾸지 않고 별도 검증기를 연결했다. 새 CLI의 경로 검사 7개와 `--help`, 같은 검증기를 사용한 Q26 CPU FP32 문단 24개의 실제 번역을 확인했다. 직접 CLI도 `The amount is unchanged.`를 `금액은 그대로다.`로 번역하고 정상 종료했다(입력 6·생성 5토큰, 생성 5.906초, 경고 없음). 전체 모델 준비 시간과 생성 시간을 구분하며 앱 제공자는 바꾸지 않았다.

```powershell
.venv-training/Scripts/python.exe -X utf8 scripts/model-comparison/infer_quality_v5.py --run-id finance-v5-terminology --device cpu --text "The amount is unchanged."
```

`--text`를 생략하면 UTF-8 표준 입력을 읽고 `--device xpu`로 Intel XPU를 선택할 수 있다. 부모·선택 체크포인트·모델·토크나이저·학습 코드·평가 식별값을 확인한 뒤 원시 FP32 번역을 생성하며 용어 보정·번역 메모리를 적용하지 않는다. 최종 시험 본문·예측을 읽거나 다시 소비하지 않는다. 부모/후보의 토크나이저 5파일은 바이트 동일하며 `special_tokens_map.json`의 동일 특수 토큰 문자열/기본 옵션 객체 표현만 엄격히 허용한다. 변경 토큰·추가 옵션·중복 키는 거부하고 원래 모델 바이트·학습·평가 기록은 보존한다. 상세 증거는 [전체 품질 비교 기록](../model-comparison/QUALITY_LOCAL_REPORT.md)에 있다.

앱용 변환·등록은 별도 검증이 필요한 후속 단계다. v5의 부모 모델 lineage는 기존 앱 배포 도구의 원본 기반 가정과 다르므로 이를 지원하기 전에는 기존 export/register 명령에 v5를 넣지 않는다. 현재 앱은 Argos다. `.training/` 가중치·체크포인트·optimizer·평가 기록은 SQLite 백업에 포함되지 않으므로 별도 보관한다.

## 현재 검증

출판 자료·모델 inventory·FP32 추론·익명 검토 도구를 포함한 전체 helper 144개 검사를 먼저 통과했다(29.124초). 이후 익명 대조 결과의 전체 범위·원문/번역 변조·해시·미완료 검증을 포함한 집계 도구를 추가하고 전체 159개 검사를 통과했다(학습 동시 실행 중 114.768초). 실제 부모 모델·선택 체크포인트의 9개 파일 해시와 step 218 lineage를 확인했다. 이 검사 통과를 실제 v5 학습 성공으로 표시하지 않는다. 확정 데이터 해시·본학습·dev/test 결과는 실행 후 이 문서에 이어 기록한다.
